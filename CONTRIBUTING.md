# Contributing

Read `docs/implementation-plan.md`, `IMPLEMENTATION_PROGRESS.md`, and `docs/EDITORIAL_WORKFLOW.md` before changing content.

Use original writing with traceable citations. Keep generated official metadata, curated bibliography/rights records, and Markdown explanations separate. Do not mass-generate apparently finished essays. A page is not researched merely because it exists.

Run `npm run check`, `npm test`, `npm run build`, and `npm run test:e2e` before proposing a release. Use `npm ci` with Node 24.22.0. Document runtime instructions are in README. All dependencies are pinned in package-lock.json.

Code is MIT licensed. Site-authored explanatory prose is CC BY 4.0. Source metadata and third-party materials retain their own rights. Do not commit research copies, secrets, restricted files, or personal local service addresses.
